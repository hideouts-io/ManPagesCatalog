# Documentation-to-command workflow

Research snapshot: 29 September 2026. This comparison inspects source, documentation, licenses, repository activity, and selected open reports. It is not a comparative usability benchmark. “Not found” describes the inspected material, not proof that a feature does not exist. Upstream issue reports are not independently reproduced here.

Keep the existing repository and history. Python is a historical comparison baseline, not a second maintained application. A future major-version release can communicate the native migration without splitting issues, links, users, or maintenance. No remote migration is required.

Accessibility evidence differs across these projects. Native controls, terminal keyboard navigation, and web keyboard shortcuts are visible in their source/docs; equivalent screen-reader usability has not been established. Our controls receive stable identifiers, while full VoiceOver certification remains unverified.

## Ranked opportunities

1. **Attributed editable drafts:** high beginner benefit, modest effort, reliable separation from execution. Retain original source path while the user edits; show common placeholder errors and require review after edits. Differentiation is the installed-manual context, not inventing interactive examples.
2. **Optional PTY alongside the manual:** high workflow benefit, greater lifecycle/packaging effort. Use SwiftTerm; explicit Start or Run only. Keep search, reading and Find available. Run a draft in a fresh shell rather than guessing whether an existing shell prompt is empty or another program owns its input.
3. **Stronger source/version context:** high correctness benefit and modest UI effort; deeper compatibility checks are expensive. Keep existing distinct source paths and honest PATH-name resolution now. Defer package-version mapping and provenance-aware example catalogs until a reliable source is selected.

The implemented milestone combines 1 and 2. It preserves HTML and PDF export. Curated/network-fetched examples, saved drafts, bookmarks, automatic option explanations, SSH, multiplexing, AI execution, deeper disk discovery, and new branding remain outside it. Session behavior and operating limits are documented once in the README.
